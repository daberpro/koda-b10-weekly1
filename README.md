# Koda B10 Weekly 1

Project ini merupakan latihan mingguan pertama untuk program Koda B10. Repositori ini dibuat menggunakan JavaScript dan ditujukan untuk mempelajari dasar-dasar pengembangan aplikasi dengan bahasa pemrograman JavaScript.

## Teknologi yang Digunakan
- JavaScript
- Node.js
- npm

## Persyaratan
Sebelum menjalankan project, pastikan perangkat Anda sudah memiliki:
- Node.js
- npm

## Instalasi
Clone repository ini ke komputer anda:

```bash
git clone https://github.com/daberpro/koda-b10-weekly1.git
cd koda-b10-weekly1
npm install
```

## Menjalankan Project
Untuk menjalankan project, gunakan perintah berikut:

```bash
npm run dev
```
